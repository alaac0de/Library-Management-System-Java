# Library Management System (Java & Data Structures)

## Overview
Designed and developed a complete Java-based Library Management System built from scratch to handle real-time library operations—including inventory tracking, membership management, borrow request handling, and return processing.

## Key Technical Features
* Custom Data Structures Implementation: Built a Doubly Linked List for books, a Singly Linked List for members, a Linked-List-based Queue (FIFO) for borrow requests, and a Custom Stack (LIFO) for tracking returns.
* Algorithm Implementation: Integrated manual searching and sorting algorithms (Bubble Sort with data swapping) to organize books dynamically by title or author.
* OOP Architecture: Designed a modular, object-oriented system structure linking nodes, data structures, and the central controller (LibrarySystem).
